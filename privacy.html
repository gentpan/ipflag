IP Flag - 隐私政策

生效日期：2026 年 8 月 2 日

概述

IP Flag 是一款浏览器扩展，用于显示您访问网站的服务器所在国家国旗及 IP 地理位置信息。我们高度重视您的隐私。

数据收集

本扩展收集以下数据：

  • 网站主机名：将当前网站的主机名发送到 IP Flag API，用于查询网站服务器对应的 IP 地理位置信息，包括国家、城市、坐标等。这是网站服务器的位置，而非您本人的位置。

数据不收集

本扩展不收集以下任何数据：

  • 个人身份信息（姓名、邮箱等）
  • 浏览记录或历史
  • 用户活动（点击、滚屏等）
  • 网站内容
  • 密码或财务信息

数据使用

查询到的 IP 地理位置信息仅用于在扩展界面中向您展示。结果缓存在浏览器本地的 session storage 中，浏览会话结束后自动清除。

数据共享

本扩展不出售或用于广告画像。网站主机名仅发送到 IP Flag API 以完成查询，不包含页面内容、账号信息或密码。

为完成地理位置查询，IP Flag API 会将解析出的服务器 IP 转发给第三方地理位置服务商 ipapi.is。转发的内容仅为该 IP 地址本身，不包含主机名、页面内容或任何可识别您身份的信息。查询结果在服务端缓存最长 30 天，以减少重复请求。

第三方服务

  • ipapi.is - 主要的 IP 地理位置数据提供方，接收待查询的服务器 IP 地址
  • IP Flag API - 本项目自有服务，在 ipapi.is 不可用时改用本地 DB-IP Lite 与 MaxMind GeoLite2 数据库作答，此时不产生任何对外请求
  • map.bluecdn.com - 提供地图图片显示

数据来源署名

兜底数据库按其许可要求署名：

  • IP Geolocation by DB-IP（DB-IP Lite，CC BY 4.0）
  • GeoLite Data by MaxMind
